読み方:

- **365 版**= 「この 1 年のふつうと比べて今日はどうか」。**季節の波は残る**(浦和 冬 +0.9 / 夏 −1.0、船橋 冬〜春 +0.9 / 夏 +1.1)。
  夏に「速い」、冬に「時計かかる」と出るのは事実として正しいが、それを「今日の馬場」として読ませることになる。

  どちらを出すかは見せ方の選択であって微調整ではない。

## 4. ユーザーが決めること

1. **標準の窓をどちらにするか**(既定は 365 版で置いてある)。
   - (i) 絶対的な速さを見せたい → **365**(夏は速く出る。画面に「夏は速く出ます」の一言を足すか要判断)
   - (ii) 例年比の「その日の馬場」を見せたい → **season**(`--baseline season` に変えるだけ。workflow の 1 行)
2. **当日の断り文の言い回し**。いまは 狭い所=「−0.5秒(途中まで)」・見出し=「馬場差 −0.5秒 速い 当サイト推定 途中まで」。
3. **切替時の作り直し**。窓を変えると過去の値の意味が変わるので、初回だけ `--rebuild-all` で 90 日を組み直す必要がある
   (`base` が前回と違うと自動で全組み直しになるようにしてあるので、実際には付けなくてよい)。
4. **§17 の案 3(過去のレース画面に結果由来の値を出してよいか)は手を付けていない**。
   ⛔「レース画面は発走前の値だけ」とぶつかる論点なので、別途ユーザー判断。
