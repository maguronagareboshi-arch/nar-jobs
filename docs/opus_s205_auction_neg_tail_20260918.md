# §205 オークション健康の打ち消し= 「〜たことはなく/〜が出ることはありません」を落とす(Opus・nar-jobs) 2026-09-18

## 出どころ

- 「歩様が乱れ**たことはなく**」(ユリヤテソーロ・ケイアイテア・サンライズホープ)
- 「跛行**するようなことはなく**」(ブラックパロット)

## 変える所(cloud/horse_health.py だけ・⛔主催者出典の GROUP_RULES は触らない)

**B. 落とした語の次の候補**= 今の finditer の `continue` で既にそうなる(打ち消された語は飛ばして次の一致を取る)= 変えない。次の語も無ければ symptom なし= 事象にしない(AUCTION_PLAIN_NEG の扱いと同じ)。
