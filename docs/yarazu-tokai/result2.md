## ⑤ 判定

痕跡なし: 境目×的の時期の 5着内率の差は 95% 区間が 0 を含む(または + の向き)。(前回= 痕跡なし)

(5着内率・両場: 境目 -・差の差 -・安全 -2.9 [-16.2, +10.8]・Ｃ境目 -・偽 −45 -31.5 [-71.8, +29.3]・偽 +45 -・印を除く境目 -・印を除く差の差 -)

差= 層(級×前2走の着順合計×人気×前走からの間隔)ごとの(的 − 対照)の「実際 − 見込み」を的の走の数で重み付け。95% は馬ごとのクラスタ bootstrap 1000 回(全部の比べで同じ重み)。対照 20 走未満の層は捨てる。
