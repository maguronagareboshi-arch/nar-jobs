# 紙面の馬具が 0 走だった件(2026-09-15 10R)— 下調べと修正

- 読んだもの: 2026-09-15 10R の紙面 PDF(一覧から拾った無印= A3 1 枚・1 ページ)。`cloud/paper_first3f.py` の grid / ocr_lines と `cloud/paper_pdf.py` の parse_block をそのまま通した(300dpi・ページ 2481×3509)。
- 馬の列 13・各列の過去走の枠 4 段= 52 段。表の「字」は⑨相手の馬の帯(枠の高さの 90% 以上)に文字認識が返した箱を左→右に並べたもの(括弧は信頼度)。
- 直す前= 便と同じ判定(帯の字が 1 つでも信頼度 0.8 未満なら読まない・それ以外は帯の字をつないで gear_marks)。直した後= `gear_from_band`。

## 結果

| | 馬具が入った段 |
|---|---|
| 直す前 | **0 / 52**(便の「馬具 0 走」と一致) |
| 直した後 | **21 / 52** |

## 原因(3 つのうちどれか)

1. **帯の位置 = 原因ではない**。⑨の字は全列で枠の高さの 95〜96% にあり、帯(90〜101%)に入っている。
2. **GEAR_TAIL の規則 = 主因**。規則は「日本語の字の直後に B/P/S」を求めるが、文字認識は**カタカナの馬名をほとんど返さず**、印だけを別の箱(「B」「BS」「B S」)で返す= 直前に日本語の字が無く、すべて外れた(列 2・3・8・9・12 の 16 段)。
3. **信頼度の閾値の当て方 = 副因**。名前を返しても信頼度 0.5〜0.7(「夕」「ジ」「シ↑」「J儿」)で、**帯の 1 字でも 0.8 未満なら帯ごと読まない**ため、0.98〜0.997 の印の箱も捨てていた(列 1 段 2・列 8 段 1・列 9 段 4・列 12 段 2)。

## 直し方(⛔推定は増やさない)

`gear_from_band(band)`:
- ① 右端から続く箱が **B/P/S だけ**(合わせて 1〜3 字)なら印の箱とし、**その箱の信頼度だけ**で決める(0.8 未満なら読まない)。名前の箱が無い・低いことは問わない。
- ② 印の箱が無い(名前と印が 1 つの箱)ときは従来どおり、全部の信頼度が足りるときだけ gear_marks。
- 崩れた字(「SA(EXYIHYE」)・名前と印が 1 つの箱で信頼度が低い(「八S」0.590)・印の箱の信頼度が低い(「S」0.577)は**読まないまま**。
