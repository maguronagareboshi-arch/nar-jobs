## 乙の決定(ユーザー 9/23 15:15)

| 馬 | URL | canonical |
|---|---|---|
| 同名のいない馬 | 今のまま `/horse/nar:<馬名>` | 自分 |
| 同名馬(同じ馬名で生年が 2 つ以上) | **全部** `/horse/nary:<生年>:<馬名>` | 自分 |
| 同名馬の `/horse/nar:<馬名>` | 選び分けページ(混ぜない) | 自分(index 可) |
| 既存 `narb:<生年月日>:<馬名>`・`kochi:<11桁>` | 読み続ける | 同名馬なら `nary:<生年>:<馬名>`、同名でなければ `nar:<馬名>` |
| `narc:` | **作らない** | — |

- 生年= 生年月日があればその年、無ければ 開催年 − 馬齢(日本の馬齢は 1/1 加算)。全期間で使える。
- 血統登録番号(nar_horse_codes・毎朝取得済み)は **馬ページの表示と公式リンクだけ**。URL の鍵にしない。
- 同名かどうかの判定は、そのページで引いた走を生年で束ねて 2 群以上か、で決める(同名表が読めなくても壊れない)。リンクを作る側は nar_meta `horse_homonyms`(馬名の配列)を 1 日メモで使い、読めなければ全部 `nar:<馬名>`(選び分けが受ける)。
- 既存の不具合も直す: `narb:` は `birth_date=eq.` で絞るため 2022-10 以前の走が消える(data.js horseNar)。馬名で軽い列を引き(同名は limit 1000)手元で生年一致で絞る。
- DB は案 X(新表 nar_horse_profiles・DDL はユーザー)。**表がまだ無くても動くこと**(404/エラー時は nar_horses を馬名で引く今の動きに戻す。同名馬は血統を「不明」)。
- 同じ馬名・同じ生年の 2 頭(旧期)は分けられない= 残る穴。差 1 年の割れ(24 名)は nar_meta `horse_homonym_merge`(手で持つ・無ければ空)で束ねられる口だけ作る。
- マイホース・メモが `nar:<同名の馬名>` で保存されていたら、選び分けページで「どちらの馬か」選ばせて移す。
