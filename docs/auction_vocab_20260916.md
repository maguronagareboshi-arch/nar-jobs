### 4-2 打ち消しの取りこぼし(34 文 / 33 出品)= `NEGATIVE_HEALTH_RE` の穴

いまの規則は「異常はありません。」のように**文末が「なし/ありません/ございません/ない」**の形しか消せない。
連用形(「〜はなく、」)と、条件の語が「異常・疾患」以外の形が抜けている。

| 言い回し | 文 |
|---|---:|
| 〜異常はなく(、) | 7 |
| 問題なく使って(きました) | 5 |
| 問題ありません / 問題はありません / 問題はなく / 問題ないとのこと | 9 |
| (〜は)認められません | 4 |
| 疾患などなく / 疾患等もなく | 2 |
| 不調はありません | 1 |
| 異常は見つかりません / 異常が出たことはありません | 2 |
| 痛みもない / 痛みや熱感は出ていません | 2 |
| 後遺症等は見られません / 気になるところはありません | 2 |

## 5. D= 本当に不明(117 文 / 92 出品)

どれも**この文だけでは病名も部位も分からない**。型は 3 つ。

1. **前の文の続き**(最多)= 「手術は受けていません。」「全治3ヶ月の診断。」「損傷率20%以上との診断。」
   「治療のため休養が長くなりました。」「保存治療の上レースに復帰しています。」。病名は**1 つ前の文**にある。
2. **保険・見舞金の話**= 「見舞金9号(競走中6か月)を受給し手術を実施しています。」
   「本馬は左前脚の疾患により、競走能力喪失の判定(…)を受けているため、競走に供することはできません。」(4 文)。
   ⇒ 「競走能力喪失」は分類の名前として立てる値打ちがあるが、607 文では 12 文と少ない= **要判断**。
3. **一般の言い回し**= 「治療が終われば、また自慢の決め手で活躍してくれると思います」など、
   売り文句の中に「治療」の字があるだけの文。

⇒ 段 2 で語彙を足しても、この 92 出品は review のまま残る(**それでよい**= 推定で病名を作らないため)。

## 6. 語を足したとき既存の判定が変わりうる例(④)

足す語を、**今は何も出していない文**(分類も unknown も付いていない文)に当ててみた結果。
数が大きい語は「部位の名前だけ」「道具の名前」で、健康の事象でない文にも当たる。

| 語 | 新しく当たる文 | 当たってしまう中身(名前は書かない) |
|---|---:|---|
| 蹄 | 202 | 蹄鉄・装蹄・削蹄・落鉄・競走名の「駿蹄賞」・種牡馬の紹介文 |
| 歩様 | 206 | 「歩様は問題ありません」「歩様も改善しています」= 打ち消しの側 |
| 球節 | 168 | 「球節に負担がかかりがち」= 体つきの話 |
| トモ | 125 | 「トモが弱く」「腰からトモにかけて」= 体つきの話 |
| 骨瘤 | 102 | 「骨瘤が治まればやれる馬」= 事象として拾ってよい文も多い(要判断) |
| ソエ | 36 | 「ソエもすっかり落ち着いています」 |
| 飛節 | 26 | 部位だけの言及 |
| 背腰 | 24 | 「背腰に疲れが出た」= 疲れは事象でない |
| 打撲 | 13 | 「歩様は問題ない様子です」と同じ文に入っていることが多い |
| 触診痛 | 16 | 「触診痛はありません」= 打ち消しの側 |
| 熱発 | 9 | 過去の体調の話 |
| 骨片 | 11 | 「骨片などの剥離は認められませんでした」= 打ち消しの側 |
| ボルト | 5 | **馬名**に「ボルト」が入る紹介文 |

**足すなら狭い形で**(数字は「607 文」/「今は静かな文」):
歩様 → `歩様が乱れ` 8 / 9・球節 → `球節に腫れ` 2 / 14・ボルト → `ボルト固定` 2 / 0。
素のままで足してはいけない語= **蹄・歩様・球節・トモ・飛節・背腰・ボルト**(7 語)。

また、打ち消しの側(4-2)を**先に**入れないと、A の語を足したとたんに
「歩様は問題ありません」「触診痛はありません」「骨片などの剥離は認められませんでした」が
健康の事象として画面に出る。**順番= 打ち消し → 分類の語**。
