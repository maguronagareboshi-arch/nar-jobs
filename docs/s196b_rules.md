## 前提(制度の開始と数え方)

- 開始日: 「令和６年１月１日より、従来の賞金額の積み上げ方式による格付から、格毎に統一した数値「格付ポイント」を設定」(L218)
  - → 2023 年以前の走に、この点数表は当てはまらない。
- 番組ポイント: 「１着から５着までの着内ポイントの合計です。」(L231)
- 数える範囲: 「原則として当該競馬の前々開催(南関東４競馬開催日割を基準とする)までに獲得したもの」(L232)
- 他地区の地方競馬: 「他地区地方競馬競走(ダートグレード競走除く)については１着から５着までの着内賞金に１万で除したものをポイントとします。」(L233)
- 遠征(他地区)のポイント: 「原則的に、獲得賞金額を１万で除したものがポイントとなります。」(L224)
  - 例外: 「地方主催のダートグレード競走については、賞金基準額が共通であることから、格付ポイント表に基づいたポイントとなります。」(L225)
- 着内ポイント表と格付基準の数値は、原文の表(L235〜L486、L495〜L621)と一致することを確かめた。
  - 記憶メモ `nankan-kakuzuke-points.md`(2026-07-10 採取)と全セル一致。
  - `tools/nankan_recon.py` の定数 `T_SPECIAL` / `T_NORMAL` / `T_JUN` / `T_JPN` / `TH` に写した。
  - 表の注記:
    - 「※GⅠについては、地方主催レース。」(L486)
    - 上半期の 3 歳 C3 は「※0」で、「※4月以降は20以上」(L551・L556)
    - 上半期の 3 歳 C1・C2 は空欄(表に値が無い)
    - 下半期の 3 歳 C3 は「20」(L617)

- **移行時**(2023 年以前の賞金の換算): **原文に無い**。
  - 開始日の文(L218)だけで、換算の方法は書いていない。
  - ⚠ 記憶メモには「移行時は旧賞金を１万で除して換算」とあるが、2026-09-17 の原文には無かった。この文書では使わない。
- **2 歳→3 歳**(3・4 歳馬の格付時期):
  - 「3・4歳馬は､概ね下表の時期において格付します｡」(L623)

## ④ 同着・失格/降着・出走取消/競走中止

- **同着**: 「同着となった馬の頭数に相当する着順までの総ポイント数を同着頭数に等分してポイントを付与します。」(L222)
- **失格・着順変更**: 「勝馬確定後に失格及び着順変更があった場合は、変更後の着順による着内ポイントで算定します。」(L234)
- **出走取消・競走除外**: **原文に無い**。
  - 走っていないので、着内(1〜5 着)に入らない。
  - 下調べでは 0 として数えた(L231 の「１着から５着までの着内ポイントの合計」による)。
- **競走中止**: **原文に無い**。
  - 着順が無いので着内に入らない。
  - 下調べでは 0 として数えた(同上)。
