# 騎手コメントの分類の表(v2・10/31)

v2 の変更: ashishitsu・course・shiage を足した。kyumei を kankaku(休み明け・連闘・間隔)に広げた。baba・kyori は向きが書かれていなければ v を省いて付ける(「馬場が合わなかった」= baba・s=-)。「最後止まった・伸びなかった」はその日だけの話でも shimai_amai に付ける(回数で癖が見える)。「相手が強い」「メンバー次第」は付けない。「ここでは厳しい」「力が足りない」は chikara。

対象= 高知のレース後コメント(騎手の話)。1 文に 0〜複数の話を付ける。**馬の特徴・癖・好み・状態**だけ。レースの経過だけの話(「相手が強い」「展開が向いた」「よく頑張った」)は付けない= 空でよい。
各ラベル= { k: 鍵, s: 良し悪し(+ 良い面 / - 課題 / 0 好み・どちらでもない), v: 向き(下の表で指定がある鍵だけ), e: 根拠の言葉(原文から 15 字以内をそのまま) }

## v2.1 の明確化(10/31 精度測定のあと)
- senko は「前に行く競馬が合う・行けないと厳しい・逃げたい」という**好み・条件**だけ。「逃げてよく残った」「ハナに行けて気分よく走った」「番手でも競馬できた」のような**その日の経過**には付けない。
- ikiashi- は「行き切れなかった」「ついて行けなかった」「進みが悪い」「追走いっぱい」など序盤の行き脚の不足に付ける(その日だけでも付ける)。
- kyori は「長い割に粘った」「この距離にしては」「1300mでは厳しく」のような**譲歩・条件の言い方でも**距離が合わない意味なら付ける(v は書いてあれば)。
- baba で向きが書かれていない良い面(「馬場が向いた」「馬場も味方した」)は s=+ にする。
